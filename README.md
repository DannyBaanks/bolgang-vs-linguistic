# BOLGANG VS LINGUISTIC — Roadmap

> A passive-aggressive experiment in making GitHub Linguist's observable behavior run through ordinary Classic Malbolge.

No upstream inclusion is requested.

This repository is not an argument that Malbolge satisfies GitHub Linguist's adoption policy.
It asks a separate and considerably stupider question:

> **Can the language detector run through the language it would not admit?**

## Target

Primary target:

```text
Classic Malbolge
10 trits per memory word
59049 memory cells per VM incarnation
```
