# Claim Firewall

## Frozen central law

```text
IF THE HOST COMPUTES A LINGUIST LANGUAGE DECISION,
THE DEMONSTRATION FAILS.
```

The host may:

- launch Classic Malbolge processes,
- pipe exact raw bytes,
- provide deterministic raw input streams,
- persist exact opaque anchors/pages emitted by Malbolge,
- re-feed those exact bytes,
- record timing/PIDs/hashes,
- present final output,
- run the upstream oracle separately for comparison.

The host may not:

- decide a language,
- preselect a language record based on extension,
- evaluate Linguist heuristics for Malbolge,
- parse a modeline/shebang and hand Malbolge the answer,
- semantically interpret an anchor,
- reconstruct logical state from an anchor,
- fabricate expected intermediate states,
- fix or normalize Malbolge's answer.

## Claim ladder

```text
C0_CLASSIC_RUNTIME
ordinary Classic VM executes the candidate artifact

C1_PRIMITIVE
one Linguist-relevant semantic primitive executes in Classic Malbolge

C2_ANCHOR
Malbolge owns checkpoint construction and resume decoding

C3_MULTI_EPOCH
one logical computation crosses >=3 fresh dead/reborn Classic VMs

C4_FILE_CLASSIFICATION
one file classification matches upstream without host decision

C5_REPO_PROCESS
repository-level language aggregation executes through Classic epochs

C6_CORPUS_PARITY
frozen observable corpus matches upstream
```

## Forbidden claims until evidence

```text
FULL_LINGUIST_LITERAL_RUBY_IMPLEMENTATION = NOT_REQUIRED
```

The target is **observable Linguist behavior**, not a literal Ruby source port.
